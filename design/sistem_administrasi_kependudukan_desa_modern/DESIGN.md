## Brand & Style

### Personality & Emotional Response
The system embodies the authority, clarity, and diligence of modernized public sector governance in Indonesia. It balances official administrative stature (*berwibawa*) with contemporary civic accessibility. The user experience conveys calm operational control, zero friction during dense data manipulation, and unwavering accountability. Visual noise is minimized to reduce cognitive fatigue for village administrators (*Perangkat Desa*) handling high-volume daily registrations, civil records, and social aid distribution.

### Design Movement: Modern Civic Enterprise
A bespoke blend of **Corporate / Modern Enterprise** and **Tonal Precision Grid**:
- Structured structural surfaces with crisp hairline division lines.
- Dense information hierarchy engineered specifically for wide backoffice displays.
- Dignified and grounded deep emerald accents anchored by architectural slate layers.
- High-contrast operational status tags to guarantee unmistakable legal verification states.

## Colors

### Palette Architecture
The color palette reflects institutional integrity, legibility, and high-contrast status feedback:

- **Primary (`#047857` Emerald 700 / `#065F46` Emerald 800):** Represents territorial governance, village welfare (*Desa Asri*), and verified official records. Used for critical action buttons, active navigation states, and primary document seals.
- **Secondary (`#1E293B` Slate 800 / `#334155` Slate 700):** Anchors administrative chrome, heavy sidebar backgrounds, persistent top-level context headers, and strong typography.
- **Tertiary (`#0284C7` Sky 600):** Designates civilian services, open workflows, citizen self-service counters, and demographic exports.
- **Neutral Base (`#F8FAFC` Slate 50 to `#F1F5F9` Slate 100):** Clean, non-glare canvas tones engineered for 8+ hour continuous desk shifts.
- **Semantic Accents:**
  - **Approval / Verifikasi:** Emerald (`#059669` / Surface `#ECFDF5`)
  - **Pending / Perlu Tindakan:** Amber (`#D97706` / Surface `#FFFBEB`)
  - **Mutasi / Pindah Masuk-Keluar:** Sky (`#0284C7` / Surface `#F0F9FF`)
  - **Ditolak / Pembatalan NIK / Kematian:** Rose (`#E11D48` / Surface `#FFF1F2`)

## Typography

### Structural Decisions
- **Plus Jakarta Sans** leads all operational interfaces, document headings, and data labels. It delivers an authoritative yet modern identity, perfectly aligning with national digital transformation standards.
- **Inter** is deployed for tabular numbers, NIK/KK identification strings, form metadata tags, and status chips, ensuring monospace tabular digits align reliably across thousands of ledger rows.
- **Typographic Scale:** Built on a tight 13px base for high-density enterprise desktop usage, maximizing viewport real estate for detailed citizen registry lists and multi-column forms.

## Layout & Spacing

### Layout Architecture
- **Layout Model:** Fixed left structural sidebar (width: 280px default, 80px collapsed) with a fluid data canvas designed for full desktop displays (1366px to 1920px+).
- **Sub-Header Administrative Bar:** Fixed-height (56px) bar displaying active territorial hierarchy (Provinsi > Kab/Kota > Kecamatan > Desa/Kelurahan > RW/RT) alongside active user credentials (*e.g., Operator Pelayanan, Kasi Pemerintahan, Kepala Desa*).
- **Grid Structure:** 12-column responsive grid with a compact 16px gutter on inner working canvases, scaling to 24px on wide displays.
- **Data Density:** Layout uses tight component padding (`space-xs` and `space-sm`) inside tables and filters to eliminate wasteful scrolling during continuous record processing.

## Elevation & Depth

### Low-Contrast Outlines & Tonal Surface Layers
To support enterprise reliability and reduce eye fatigue, the design system rejects harsh, drop-shadow-heavy layers in favor of crisp hairline delineations and tonal surface hierarchy:

1. **Canvas Base (`Level 0`):** `#F8FAFC`. Background for backoffice operations.
2. **Surface Resting (`Level 1`):** `#FFFFFF` paired with an administrative hairline border (`1px solid #E2E8F0`). Used for table containers, filter cards, and inspection drawers.
3. **Elevated Overlays (`Level 2`):** Dropdowns, search autocompletes, and quick-filter modals use `box-shadow: 0 4px 12px -2px rgba(15, 23, 42, 0.08), 0 2px 4px -2px rgba(15, 23, 42, 0.04)` combined with `border: 1px solid #CBD5E1`.
4. **Modal Dialogues & Verification Overlays (`Level 3`):** Critical approval dialogs (e.g., penandatanganan surat, cetak KTP-el/KK) use a subtle deep-slate blur overlay (`background: rgba(15, 23, 42, 0.45); backdrop-filter: blur(2px)`) with focused floating containers (`box-shadow: 0 20px 25px -5px rgba(15, 23, 42, 0.15)`).

## Shapes

### Compact Precision Geometry
- The roundedness scale is set to **Soft (`1`)**, providing crisp, institutional structure suitable for high-density public registry software.
- Standard form inputs, buttons, and alert callouts use `4px` (`0.25rem`) radius to preserve maximum interior working room.
- Data containers and analytical summary cards utilize `rounded-lg` (`8px` / `0.5rem`).
- Regional selector pills and workflow state chips utilize `rounded-full` to stand out cleanly from tabular cell boundaries.

## Components

### 1. Territorial Context & Role Header
- A persistent context ribbon positioned above main screens.
- **Territory Scope Selector:** Interactive dropdown segment displaying breadcrumb-style hierarchy (`Kec. Sukamaju / Desa Karangtengah / RW 04`).
- **Role Pill:** Encapsulated badge styled in Slate-800 (`#1E293B`) background with Emerald accent pip (`#10B981`) indicating active operator permissions.

### 2. High-Density Data Tables
- Header cells: `#F8FAFC` background, uppercase 11px typography (`label-md`), `#475569` font color, `1px solid #E2E8F0` bottom border.
- Row padding: `8px 12px` to balance density with misclick prevention.
- Alternate row striping using `#FCFDFD`.
- Identification numbers (NIK / No. KK) rendered with tabular fonts and direct copy-to-clipboard actions.

### 3. Status Badges & Mutation Chips
- **Disetujui / Terverifikasi:** Emerald text (`#047857`) on tint background (`#ECFDF5`), border `#A7F3D0`.
- **Menunggu Verifikasi:** Amber text (`#B45309`) on tint background (`#FFFBEB`), border `#FDE68A`.
- **Mutasi Masuk/Keluar:** Sky text (`#0369A1`) on tint background (`#F0F9FF`), border `#BAE6FD`.
- **Ditolak / Arsip:** Rose text (`#BE123C`) on tint background (`#FFF1F2`), border `#FECDD3`.
- Sizing: `20px` height, uppercase 10px bold text (`label-sm`), `pill` border radius.

### 4. Input Fields & Search Bars
- Standard height: `36px` for dense data entry; `40px` for primary global registry searches.
- Inactive state: `1px solid #CBD5E1`, `#FFFFFF` surface.
- Focus state: `1px solid #047857`, subtle ring `0 0 0 2px rgba(4, 120, 87, 0.15)`.
- Family Card / Citizen form groups organized via two-column fieldsets featuring distinct divider lines.

### 5. Buttons & Action Bars
- **Primary:** `#047857` background, `#FFFFFF` text, bold weight (`label-lg`), subtle top highlight border.
- **Secondary / Action Table Button:** `#FFFFFF` background, `1px solid #CBD5E1`, `#334155` text; transitions to `#F1F5F9` on hover.
- **Danger (Pembatalan Dokumen / Hapus Data):** Crimson outline with transition to solid `#E11D48`.

### 6. Summary Metric Cards (Statistik Warga)
- White surface, `1px solid #E2E8F0`, padding `16px`.
- Left-edge accent border (3px) matching the category indicator (Emerald for Total Penduduk, Sky for Mutasi, Amber for Bansos Aktif).
